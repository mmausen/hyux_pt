# AIHighlight

Marks individual values that AI created or changed, in the information value state, so people can see what to check.

**Markup:** text `<span class="fh-ai-mark">Oct 24, 2026</span>`; fields `<span class="fh-input fh-input--ai"><input …><span class="fh-icon" data-icon="ai"></span></span>`. Offer a "Show AI Highlights" Switch for low and medium impact; keep highlights on for high impact. Once a person edits or confirms a value, remove its highlight.
