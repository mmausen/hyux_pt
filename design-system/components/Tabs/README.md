# Tabs

Switches between sections of an object page or views of a list; text tabs with a .1875rem `sapHighlightColor` underline on the selected tab.

**Markup:** `<nav class="fh-tabs" role="tablist"><button class="fh-tab" role="tab" aria-selected="true">General Information</button>…</nav>`; counts go in `fh-tab__count`. Title case labels, at most about seven tabs.
