# ObjectPageHeader

The header of an object page: optional object image, breadcrumb, title in 72 Black 1.5rem, status, header actions, subtitle and key attributes, followed by the anchor bar (Tabs).

**Markup:** `<section class="fh-objheader">` with `fh-avatar--l fh-avatar--square`, `fh-objheader__breadcrumb`, `fh-objheader__titlerow` (`fh-objheader__title`, an ObjectStatus, `fh-objheader__actions`), `fh-objheader__subtitle` and `fh-objheader__attrs` of `fh-attr__label` / `fh-attr__value` pairs. Header actions: Edit (emphasized), Delete (default), overflow. Up to about five attributes.
