# Avatar

Represents a person (initials or photo) or an object (icon or image); circle for people, square with `sapElement_BorderCornerRadius` for objects.

**Markup:** `<span class="fh-avatar [size] [shape] [scheme]">JW</span>`. Sizes: `fh-avatar--xs` 2rem, `--s` 2.25rem, default 3rem, `--l` 5rem. Shape: `fh-avatar--square`. Color schemes: `fh-avatar--accent1|2|5|6`, or `fh-avatar--placeholder` with an icon inside. Initials are two letters, uppercase.
