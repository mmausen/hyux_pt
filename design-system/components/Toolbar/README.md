# Toolbar

Groups actions above a table or list (`fh-toolbar`) and holds page actions in the floating footer (`fh-footer`).

**Markup:** `<div class="fh-toolbar"><span class="fh-toolbar__title">Items (24)</span><span class="fh-toolbar__spacer"></span>…buttons…</div>`; separators `fh-toolbar__sep`. Footer: `<footer class="fh-footer">` with the emphasized button first, then transparent ones, right-aligned. Show the footer only in edit or create mode.
