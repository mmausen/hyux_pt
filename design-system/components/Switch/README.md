# Switch

Switches a setting on or off with immediate effect; track is `sapNeutralElementColor` off and `sapHighlightColor` on.

**Markup:** `<label class="fh-switch"><input type="checkbox" role="switch"><span class="fh-switch__track"></span>Label</label>`. Use it only where the change applies at once (settings); in forms that are saved later use a CheckBox. Geometry is modeled on UI5 Web Components (Horizon).
