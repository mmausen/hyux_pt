# QuickPrompts

Predefined AI actions in an AI menu button, with SAP's standard labels so the same action reads the same everywhere.

**Markup:** the AI menu button (see AIButton) opens `<div class="fh-menu" role="menu">` with `fh-menu__item` rows, `fh-menu__sep` separators and submenus marked by a trailing `slim-arrow-right` (`fh-menu__sub`).

**Use** the standard labels first: Generate, Regenerate, Revise, Simplify, Expand, Shorten, Change Tone, Translate. Other actions start with an imperative verb. Put the most used actions first and group the rest in submenus.
