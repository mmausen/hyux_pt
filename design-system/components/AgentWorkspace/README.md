# AgentWorkspace

The agent-first floorplan: ShellBar, a navigation rail, a main area with greeting, prompt, intents and an AI-generated space, and a side panel for what needs the person's attention.

Start every agent-first prototype from this layout; see Floorplans for the parts. Intentional addition, after SAP's Joule Work concept (intent-based workspace, generated spaces, agents working under guardrails).
