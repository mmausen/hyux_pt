# ShellBar

The top application header: product title, optional secondary title, search, notifications, help, app switcher and the user avatar on `sapShellColor`.

**Markup:** `<header class="fh-shellbar">` with `fh-shellbar__title`, `fh-shellbar__secondary`, `fh-shellbar__spacer`, `fh-shellbar__search`, `fh-shellbar__action` buttons (badge: `fh-shellbar__badge`) and an `fh-avatar--xs`. It is 3.25rem high and always at the top of the page. Place your own logo before the title; this system ships no logo (see Logos).
